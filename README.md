# Spider Solitaire

Ad-free Spider Solitaire for the phone. 1, 2 or 4 suits; works offline.

**Play:** https://shaunkpaterson.github.io/spider-solitaire/ (Chrome menu → *Add to Home screen* to install)

- Winnable deals only (default): new games come from deals a solver has already won.
- Tap or drag to move; unlimited undo; hints; stats.
- Three picture-card styles and three card backs (Menu → Cards).

**Release:** bump `CACHE` in `sw.js`. More winnable deals: `tools/generate.html`.
