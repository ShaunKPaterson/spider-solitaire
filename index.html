Every new or restarted game counts as played.

Goal: build runs from King down to Ace in one suit. Each finished run is cleared away. Clear all eight to win.

  • A card can go on any card one higher, whatever the suit: a 7 on any 8.
  • A group moves together only if it runs downwards in the same suit.
  • Any card or run can go into an empty column.
  • Tap the deck (bottom right) to deal one card onto every column.

Controls: drag a card, or just tap it and it jumps to the best place. Undo has no limit. Hint shows a good move and cycles through others if you press it again.

Winnable deals only (Menu → Game, on by default): new games are picked from deals a computer solver has already won, so a win is always possible, though you may need Undo to find it. Turn it off for completely random deals, some of which can't be won.

Tips: turn over face-down cards first, build in suit, and keep an empty column free for reorganising. Only deal when you run out of useful moves.
